# VoxBench

Automated chaos engineering, acoustic stress-testing, and latency/barge-in QA workbench for Voice AI agents (Vapi, Retell, LiveKit, Pipecat).

- **Live App:** [https://voxbench08.vercel.app/]
- **Features:**
  - 4G jitter & packet loss injection
  - Acoustic noise stress testing
  - Mid-sentence barge-in collision detection
  - Automated QA scorecards
